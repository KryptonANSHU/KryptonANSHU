## What I Built at HackerRank

**🛡️ Sanity Framework**
A validation service that catches broken assessment content *before* customers ever see it. Built with GitHub Actions, webhooks, cron jobs, and AWS EC2. It moved the team from fixing issues after reports to catching them early, and cut support tickets.

**⚖️ Parity Testing Pipeline**
Keeps scoring consistent across **700+ questions** during major stack migrations, so an upgrade never silently changes a candidate's result.

**🤖 AI Content Pipelines**
Worked on AI agent pipelines that generate and upgrade assessment content in bulk (MCQs, database questions, code repos) using LangChain, LangGraph, MCP, and prompt engineering.

> These are internal tools, so the code is private. Happy to walk through the design in a call.
